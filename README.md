# ERPNext Backend Customization – RFQ Status Change on Supplier Quotation Submission

This repository contains code from a project where I worked on backend customizations in ERPNext, specifically handling status changes in the Request for Quotation (RFQ) module when a supplier submits their quotation. The changes were aimed at automating workflow and ensuring the RFQ status reflects the correct business process.


Project Overview

ERPNext is an open-source ERP system that helps manage various business processes including accounting, inventory, sales, and purchase management. In this project, I focused on:
1. Automatically updating RFQ status when a supplier submits their quotation
2. Implementing backend logic to ensure accurate workflow and approvals
3. Triggering notifications or further actions based on the submission


Features and Changes Made
1. Automated RFQ status updates upon supplier quotation submission
2. Backend validations to ensure correct status changes
3. Customized triggers and notifications when a quotation is submitted
4. Improved workflow tracking for RFQs and supplier responses


Technologies Used
1. ERPNext – open-source ERP platform
2. Frappe Framework – web framework underlying ERPNext
3. Python – backend logic and server-side scripting
4. MariaDB / MySQL – database used by ERPNext


Getting Started

To explore or extend these customizations:

1. Install ERPNext following the official guide
2. Clone this repository into your ERPNext app directory
3. Apply the changes or custom scripts to the RFQ module
4. Test the workflow in a development environment before deploying to production
